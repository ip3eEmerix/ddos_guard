# DDoSGuard

DDoSGuard — это плагин для защиты Minecraft-сервера от DDoS-атак. Он ограничивает количество подключений с одного IP-адреса, предоставляет статистику подключений и позволяет настраивать параметры через конфигурационные файлы.

---

## Авторы

- **Основной разработчик**: [IP3E](https://github.com/IP3E)
- **Соавтор**: [SALIEVVS](https://github.com/SALIEVVS)

---

## Особенности

- Ограничение количества подключений с одного IP-адреса.
- Настройка параметров через `config.yml`.
- Локализация сообщений через `messages.yml`.
- Команды для управления плагином:
  - `/dg help` — показать список команд.
  - `/dg reload` — перезагрузить конфигурацию.
  - `/dg info` — показать статистику подключений.
- Автоматическая очистка старых записей о подключениях.
- Совместимость с версиями Minecraft от 1.16 до 1.21.

---

## Установка

1. Скачайте последнюю версию плагина (`DDoSGuard.jar`) из раздела [Releases](https://github.com/IP3E/DDoSGuard/releases).
2. Переместите файл `DDoSGuard.jar` в папку `plugins` вашего сервера.
3. Запустите сервер. Плагин автоматически создаст файлы конфигурации:
   - `config.yml` — основные настройки.
   - `messages.yml` — сообщения плагина.
4. Настройте файлы `config.yml` и `messages.yml` по своему усмотрению.
5. Перезагрузите сервер или выполните команду `/dg reload`, чтобы применить изменения.

## Конфигурация

### `config.yml`

```yaml
# Максимальное количество подключений с одного IP
max-connections-per-ip: 5

# Время (в минутах) для отображения статистики
stats-time: 5

# Интервал очистки старых записей (в минутах)
cleanup-interval: 5
